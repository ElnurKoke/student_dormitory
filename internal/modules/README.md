# Бизнес-модули

Здесь размещаются только модули с реализуемым поведением. В `audit` реализована минимальная запись событий с атомарным сохранением делового изменения. HTTP-интерфейса и прав просмотра аудита пока нет; модуль не имеет пустого обработчика. В `auth` реализованы пользователи, идентичности, разрешения, ограничения общежитиями, серверные сессии и защищённые формы. В `inventory` реализован фонд до уровня койко-места: формы, списки, архивирование, история статусов, защита версий и вместимости, транзакционный аудит. Процессы бронирования и заселения ещё не созданы.

При добавлении модуля используйте `handler.go` для HTTP, `service.go` для бизнес-логики и `repository.go` для SQL. Имена можно уточнять по содержанию. Сервис принимает контекст и предметные типы, не импортирует HTTP и зависит от узкого интерфейса репозитория, если нужна замена в проверках. SQL-реализация принимает `*sql.DB` или общий `*sql.Tx` для связанных операций. Зависимости подключаемых модулей собираются в `internal/app`; контракт аудита описан в `docs/sqlite.md`.

Не создавайте заранее модули отложенных интеграций и полного процесса размещения. Неуточнённые бизнес-правила находятся в `docs/open-questions.md`.
